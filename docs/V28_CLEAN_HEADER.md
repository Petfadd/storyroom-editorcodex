# Storyroom V28 — clean production header

Build: `2026-11-24-clean-header-v28`  
Release date: 24 November 2026

- The redundant **Projects** button has been removed from the editor header. The
  existing back arrow returns to the homepage, where productions can be opened or
  created.
- The production-management button reads **Setup** while the current production has
  no timeline scenes.
- The same button changes to **Edit** once timeline scenes are present.
- Its action is unchanged: it opens the current production's script, narration,
  subtitles, media and settings workspace.

All V27 framed-photo, collage, still-motion, preview and final-render behavior remains
included in V28.
